# Tài liệu tham khảo UI/UX

## File tham khảo

`ui-reference-phuong-an-b.html`

## Mục đích

File HTML này chỉ dùng để tham khảo:

- bố cục tổng thể;
- cách phân nhóm chức năng;
- cách trình bày bảng, biểu mẫu và trạng thái;
- màu sắc và phong cách giao diện;
- một số ý tưởng về luồng thao tác.

## Nguyên tắc sử dụng

- Không sử dụng trực tiếp file HTML này làm mã nguồn production.
- Không sao chép nguyên trạng JavaScript hoặc logic phân quyền trong file.
- Không xây database hoặc backend dựa riêng trên cấu trúc của prototype.
- Thiết kế UI/UX chính thức phải được phân tích lại về kỹ thuật, khả năng sử dụng và responsive.
- Khi prototype mâu thuẫn với đặc tả hệ thống, đặc tả phiên bản hiện hành là nguồn đúng.
- Logic nghiệp vụ, phân quyền, PPCT, bảng kê và phê duyệt phải tuân theo đặc tả.
- Prototype chỉ là một nguồn tham khảo, không phải thiết kế bắt buộc.
